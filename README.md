# CreditCalc

Учебное Веб-приложение для расчёта и сравнения кредитов.

## Возможности

- Расчёт аннуитетных и дифференцированных платежей.
- Расчёт платежей при процентной ставке 0%.
- Отображение графика погашения и суммы переплаты.
- Сравнение трёх вариантов кредита.
- Выгрузка графика платежей в CSV.
- Печать результатов и сохранение в PDF через браузер.


### Сборка и запуск

Откройте терминал в корневой папке проекта, где находится `compose.yml`, и выполните:

```bash
docker compose up -d --build
```
После запуска откройте приложение:
http://localhost:8088


### Проверка работы
Посмотреть состояние контейнеров:

```bash
docker compose ps
```

Проверить доступность backend через nginx:
http://localhost:8088/api/v1/health
При успешном запуске сервер вернёт:

```json
{"status":"UP"}
```
